# Scientific Canon

A comprehensive research repository exploring theoretical physics, consciousness studies, and semantic analysis through interactive applications and computational tools.

## Overview

Scientific Canon is a collection of interconnected research projects and applications that investigate fundamental questions about reality, consciousness, and the nature of existence. The repository combines rigorous scientific methodology with innovative computational approaches to explore:

- **Theoretical Physics**: Unified field theories, quantum mechanics, and cosmological models
- **Consciousness Studies**: Mathematical frameworks for understanding awareness and perception
- **Semantic Analysis**: Vector-based approaches to meaning, knowledge, and scientific literature

## Scientific Applications

### 1. Sky Map (Reality Studies Explorer)
**Location**: `reality-studies-explorer/`

An interactive visualization tool for exploring reality studies data. Built with React/TypeScript, featuring:
- Interactive sky map interface
- Data visualization of consciousness research
- Real-time filtering and exploration capabilities

**Setup**:
```bash
cd reality-studies-explorer
npm install
npm run dev
```

### 2. Semantic Physics Map
**Location**: `semantic-physics-map/`

Visualizes relationships between physics concepts using semantic vector analysis. Features graph-based navigation of theoretical physics concepts.

**Setup**:
```bash
cd semantic-physics-map
npm install
npm run dev
```

### 3. Canon Vector Application
**Location**: `canon-vector-app/`

A vector database application for semantic search across scientific literature. Implements embedding-based similarity search for research papers and concepts.

**Setup**:
```bash
cd canon-vector-app
npm install
npm run dev
```

### 4. Unifying Theory Application
**Location**: `unifying-theory-app/`

Interactive exploration of unified field theory concepts. Provides computational models and visualizations of theoretical frameworks.

**Setup**:
```bash
cd unifying-theory-app
npm install
npm run dev
```

### 5. Vector Journal iOS
**Location**: `vector-journal-ios/`

An iOS application for journaling with semantic vector analysis. Allows users to track ideas and find connections between entries using AI-powered semantic search.

**Setup**: Open in Xcode and build for iOS simulator or device.

### 6. Zero Instrument Workflow
**Location**: `zero-instrument-workflow/`

Audio synthesis and analysis tools for exploring sound as a medium for scientific inquiry. Includes:
- Custom instrument definitions
- Audio processing workflows
- Sound-based data sonification

## Getting Started

### Prerequisites

- Node.js 18+ (for web applications)
- Python 3.9+ (for research tools)
- Xcode 15+ (for iOS development)
- Git LFS (for large audio files)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/y494mhb6cy-tech/Scientific-Canon.git
cd Scientific-Canon
```

2. Install Git LFS (for audio files):
```bash
git lfs install
git lfs pull
```

3. Set up Python environment (for research tools):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

4. Set up web applications:
```bash
cd <application-directory>
npm install
npm run dev
```
